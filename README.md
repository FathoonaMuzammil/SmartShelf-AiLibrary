# SmartShelf – AI-Powered Library Discovery and Recommendation System

**Tagline:** Discover. Learn. Borrow.

SmartShelf is a web-based library discovery and borrowing system designed for the Faculty of Technology Library, University of Sri Jayewardenepura.

The system helps students discover academically relevant books, check availability, reserve books and receive recommendations through an AI-powered Library Assistant.

## Main Features

- Student Portal
- Lecturer Portal
- Librarian Portal
- AI Library Assistant
- Book discovery and search
- Book reservations and borrowing management
- Lecturer book recommendations
- Student ratings and reviews
- Notifications and overdue tracking

## Technology Stack

### Frontend
- React
- Vite
- Tailwind CSS
- shadcn/ui
- Lucide React

### Backend
- Node.js
- Express.js
- REST APIs
- JWT Authentication
- bcrypt

### Database
- MySQL 8.0

### AI Integration
- LLM/API-based AI Library Assistant
- Catalogue-grounded book recommendations
